# Telegram-бот «Котик дня и предсказания»

Бот для зачёта по ПМУ.

## Возможности
- `/start` — приветствие и клавиатура
- `/cat` или «котик дня» — случайное фото котика
- `/prediction` или «предсказание» — случайное предсказание на день
- `/help` — справка

## Запуск
1. Установить пакет: `dotnet add package Telegram.Bot`
2. Запустить: `dotnet run`
